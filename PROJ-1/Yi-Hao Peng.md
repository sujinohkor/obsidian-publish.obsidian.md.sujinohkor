# Slide Gestalt
슬라이드 제작자는 제목, 슬라이드, 추가되는 내용 등, 시각적 패턴으로 구조를 전달한다.
**하지만,** 그 구조가 스크린리더 사용자들에게는 충분히 전달되지 않는다.
**따라서,**
1) 슬라이드 사이의 시각적/텍스트적 관계를 분석해 계층 구조를 추출하고
2) 사용자가 전체개요 -> 슬라이드 묶음 -> 개별요소로 탐색하도록 한다.
* **유사점:** 디자인에 담긴 구조를 파악해서 비시각적 탐색으로 바꾼다.

# Morae
시각장애/저시력 사용자를 위한 UI 에이전트가, 작업을 자동으로 수행하면서 **사용자가 알아야 할 선택지를 지나쳐버림**

**예,**
1) 가장 저렴한 탄산수를 사줘
2) 같은 가격의 여러 맛이 있네
3) **시스템이 임의로 아무거나 하나 골라버림 (???)**
* 자기가 아무거나 골라버리지 말고, 선택지를 줘
* **질문점:** 시스템이 중요하다고 판단한 내용만 먼저 전달해버리면, 사용자가 직접 판단하는 데에 필요한 다른 선택지를 놓치지는 않나?
