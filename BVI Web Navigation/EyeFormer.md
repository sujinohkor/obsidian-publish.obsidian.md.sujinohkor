*[EyeFormer: Predicting Personalized Scanpaths with Transformer-Guided Reinforcement Learning](https://doi.org/10.1145/3654777.3676436)*
*Yue Jiang*

# RQ / Research Goal
- GUI·정보 그래픽·자연 장면에서 **시선 고정 위치·순서·지속시간을 포함하는 스캔패스 예측**
- 집단의 일반적 시선 패턴과 개인별 시선 행동 차이를 함께 반영하는 모델 개발
- 소량의 사용자 시선 데이터를 통한 새로운 사용자의 스캔패스 개인화
- 예측된 시선 흐름을 활용한 개인별 GUI 레이아웃 최적화 가능성 탐색

# Approach
- **transformer와 강화학습을 결합한 EyeFormer 모델 제안**
- 이미지 특징과 이전 시선 고정 정보를 입력으로 활용하여 다음 고정 위치·지속시간의 확률분포를 순차적으로 예측
- 실제 스캔패스와의 시공간적 유사도 보상 및 시각적 현저성 보상을 결합한 학습
- 이미 본 영역으로의 과도한 재방문을 억제하는 IOR(Inhibition of Return) 기제 적용
- 새로운 사용자의 **스캔패스 50개**를 활용한 사용자 표현 및 인코더의 미세조정을 통한 개인화
- UEyes의 62명·1,980개 이미지와 OSIE의 15명·700개 이미지를 활용한 데이터셋별 독립 학습·평가
- DTW·TDE·Eyenalysis·DTWD·MultiMatch를 활용한 기존 모델 비교 및 구성요소 제거 실험
- 디자이너가 지정한 요소별 주시 순서를 제약조건으로, 해당 요소의 주시시간을 최적화 목표로 설정한 GUI 배치 생성

# Findings
- **집단 수준 예측에서 대부분의 평가 지표상 기존 모델과 동등하거나 우수한 성능 확인**
- 시선 고정 위치뿐 아니라 순서·지속시간을 함께 예측하는 능력 확인
- 대상 사용자에게 개인화한 모델에서 다른 사용자에게 개인화한 모델보다 낮은 예측 오차 확인
- 개인화 비교에서 DTW 4.152→4.058, DTWD 5.070→4.996으로 개선되었으나, 절대적인 개선 폭은 제한적
- Transformer 단독 모델 대비 강화학습 적용 시 TDE 14.7%, Eyenalysis 26.5%, DTWD 4.8% 개선
- 보상함수와 IOR 적용을 통한 고정점의 과도한 군집화 완화 및 전반적 예측 정확도 향상
- GUI 최적화 사례에서 집단용 배치 대비 개인화 배치의 목표 요소 주시시간 **모델 예측값**이 각각 44.19%, 16% 증가

# Limitations
- **짧은 자유 관찰 상황과 고정 길이 스캔패스에 한정된 검증**으로 장시간 탐색·과업 수행 상황에 대한 일반화 미검증
- 개인화를 위한 사용자별 스캔패스 50개 수집 부담 및 필요 데이터량 축소 과제
- 시선 고정 중심의 모델링으로 눈 깜빡임·전정안구반사 등 복잡한 안구 움직임 미반영
- 자연 장면 중심으로 개발된 평가 지표의 GUI 특성 반영 한계
- 개인화 평가의 테스트 사용자 9명 및 기존 개인화 비교 모델 부재에 따른 검증 범위 제한
- GUI 최적화 효과의 모델 예측 중심 제시로 실제 사용자의 선호·사용성 향상에 대한 추가 검증 필요
- **설계 의도 추론 및 스크린리더 읽기 순서 개선에 대한 직접 검증 부재**—응용 사례에서 중요 요소와 목표 주시 순서를 디자이너가 사전에 제공하는 구조
