NVDA 그룹 읽기 순서 검증

화면 순서: A → B → C. 확장 프로그램 ON 후에도 화면은 동일해야 합니다.

NVDA 읽기 예상: OFF = A → B → C / ON = C → B → A. 그룹 내부는 언제나 첫째 → 둘째 → 셋째.

그룹 에이: 상품 소개

에이 항목 첫째: 제품 소개

에이 항목 둘째: 주요 특징

에이 항목 셋째: 세부 설명

그룹 비: 가격과 옵션

비 항목 첫째: 판매 가격

비 항목 둘째: 선택 옵션

비 항목 셋째: 구매 조건

그룹 씨: 사용자 후기

씨 항목 첫째: 사용자 평가

씨 항목 둘째: 좋은 평가

씨 항목 셋째: 개선 요청
