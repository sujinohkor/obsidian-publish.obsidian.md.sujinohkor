# RQ / Research Goal
- 웹사이트마다 다른 페이지 구조를 탐색하고 기억해야 하는 스크린리더 사용자의 조작·인지 부담 완화
- **사용자가 필요한 요소를 자연어로 설명하면, 해당 요소에 직접 접근할 수 있는 개인화 인터페이스 생성**
- 페이지·사이트가 바뀌어도 사용자의 목표에 맞는 제어 요소를 연결하는 일관된 탐색 경험 지원
- 사용자의 직접 조작과 원본 요소 확인을 보장하면서 탐색 노력·작업 부담을 줄이는 상호작용 방식 탐색

# Approach
- 시각장애인 보조공학 전문가 2명과의 사전 세션 3회를 통한 설계 요구사항 도출
- **원본 웹 요소와 연결된 접근 가능한 대리 제어 요소인 ‘tether’를 생성하는 브라우저 확장 프로그램 Navigal 개발**
- 사용자 요청에 맞춰 버튼·입력창·체크박스·메뉴·정보 요약 등을 별도 패널에 구성
- DOM 요소에 안정적인 식별자를 부여하고, 페이지 변경을 감지하여 원본 요소와의 연결 유지
- LLM 기반 planner–worker 구조를 활용한 사용자 요청·스크린샷·DOM 분석 및 관련 요소 검색
- 사용자가 tether를 조작할 때 원본 요소에 동작을 전달하고, 원본 위치로 이동하여 결과를 직접 확인하는 기능 제공
- 저장한 tether를 다른 페이지·사이트의 의미상 대응 요소에 다시 연결하는 적응 기능 구현
- 19개 웹사이트·12개 영역의 20개 과업에 대한 기술 평가 및 시각장애인 7명 대상 스크린리더 단독 조건과의 탐색적 비교 연구 수행

# Findings
- **20개 과업 중 15개 완전 수행, 3개 부분 수행으로 총 18개 과업 지원**
- 생성된 tether 66개 중 정확 59개(89.4%), 부분 정확 6개(9.1%), 부정확 1개(1.5%) 확인
- 공통으로 접근 가능한 39개 목표 요소에 대한 탐색 단계 중앙값 감소: 순차 탐색 39단계 → Navigal 6단계
- 페이지 구조와 최적 단축키 조합을 완전히 알고 있다고 가정한 이론적 최단 경로 4단계에 근접
- 원본 페이지에서 키보드 포커스를 받을 수 없었던 요소 27개에 대한 직접 접근 제공
- 사용자 연구에서 참가자 7명 전원의 쇼핑 과업 완료 및 Navigal 선호·지속 사용 의향 확인
- 정신적 부담·시간적 부담·좌절감·노력 감소와 주관적 수행도·탐색 효율·현재 위치 파악의 유의한 개선
- **페이지 구조를 찾아다니는 방식에서 필요한 제어 요소를 요청하고 직접 조작하는 방식으로의 전환 가능성 확인**

# Limitations
- 사용자 7명·Amazon 쇼핑 중심의 단기 탐색 연구로 다양한 과업과 장기 사용에 대한 일반화 한계
- 저장된 tether의 장기 재사용 및 사이트 간 적응 기능에 대한 직접적인 효과 검증 부족
- 양 조건에서 연구자의 도움을 허용한 실험 설계로 독립적인 과업 수행 성능 판단에 한계
- 탐색 단계 계산에서 자연어 요청 입력에 필요한 키 입력 제외로 전체 조작 비용의 과소평가 가능성
- 맞춤형 웹 위젯에서 올바른 요소를 찾아도 전달한 조작이 실행되지 않는 문제 발생
- 여러 요소가 요청에 부합하는 경우 일부 관련 요소 누락 및 부정확한 원본 연결 발생
- 기반 언어모델에 따른 정확도·지연·비용 의존성 및 기술 평가상 과업당 중앙값 약 34초·0.10달러의 처리 부담
- 일부 사용자의 일반 웹 검색 도구와의 혼동으로 현재 페이지 기반 인터페이스라는 개념의 학습 필요
