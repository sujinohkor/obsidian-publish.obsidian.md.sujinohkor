*[Morae: Proactively Pausing UI Agents for User Choices](https://doi.org/10.1145/3746059.3747797)*
*Yi-Hao Peng*

# RQ / Research Goal
- UI 에이전트가 사용자에게 알리지 않고 선택을 대신하는 과정에서 발생하는 시각장애·저시력 사용자의 선택권 및 통제권 약화 문제 해결
- **사용자 판단이 필요한 시점에 자동화를 일시 정지하고, 선호를 확인하는 UI 에이전트 개발**
- 사용자 요구가 불명확하거나 조건을 만족하는 선택지가 여러 개인 상황의 자동 감지
- 자동화의 편의성을 유지하면서 사용자 선호에 부합하는 선택과 작업 결과 이해 지원

# Approach
- 시각장애·저시력 사용자 4명 대상 1주간 현장 연구 및 후속 인터뷰를 통한 기존 에이전트의 문제점 분석
- Chrome 확장 프로그램 기반 TaxyAI를 확장한 **Morae 시스템 개발**
- GPT-4o에 사용자 명령·축약된 DOM·스크린샷·이전 행동 기록을 제공하여 다음 행동 결정
- 단계별 계획과 모호성 검증을 결합하여 **추가 정보 탐색·사용자 확인을 위한 일시 정지·자동 실행 지속** 중 적절한 행동 선택
- 일시 정지 시 라디오 버튼·입력창 등 스크린리더로 접근 가능한 선택 인터페이스의 동적 생성
- 실시간 청각 피드백, 작업 결과 검증 및 스크린리더별 수동 수행 안내 제공
- 8개 UI 유형의 256개 과업을 활용한 기술 평가 및 프롬프트·검증 방식별 비교
- 시각장애·저시력 사용자 10명 대상 Morae·TaxyAI·OpenAI Operator 비교 실험 수행

# Findings
- **사용자 선택이 필요한 과업에서 적절한 일시 정지 성능 향상**: 기술 평가 성공률 Morae 65.6%, Operator 50.8%
- 전체 기술 평가 성공률 Morae 55.2%, Operator 53.1%로 소폭 개선
- 일시 정지 감지 성능에서 정밀도 59.7%, 재현율 69.8%, F1 64.4% 기록
- 사용자 연구에서 선호에 부합하는 평균 선택 수 증가: TaxyAI 1.92개 → Operator 2.98개 → Morae 4.03개
- 사용자 연구에서 평균 성공 과업 수 증가: TaxyAI 2.60개 → Operator 3.90개 → Morae 5.50개
- 선택 만족도·선택지 인지·통제감·선택 용이성 향상 및 참가자 전원의 Morae 선호
- 행동·결과에 대한 실시간 피드백을 통한 에이전트 수행 내용과 결과의 이해 향상
- **선택 참여 확대에 따른 시간 비용 증가**: 평균 과업 소요시간 TaxyAI 55.7초, Operator 86.6초, Morae 129.4초

# Limitations
- 일시 정지 감지의 불완전성으로 불필요한 중단과 필요한 중단의 누락 발생
- 일시 정지가 불필요한 과업에서 Operator보다 낮은 기술 평가 성공률 기록: Morae 44.8%, Operator 55.5%
- 사용자 확인 과정에 따른 과업 수행시간 증가 및 효율성과 통제권 사이의 절충 필요
- 중단·진행의 이진 정책으로 개인별 개입 선호와 과업의 중요도를 세밀하게 반영하는 데 한계
- 여러 차례의 선호 확인이 필요한 복잡한 다목적·장기 과업에 대한 검증 부족
- 소규모 참여자 및 제한된 사용자 연구 과업에 따른 일반화·장기 사용 효과 검증의 한계
- 웹 환경과 클릭·값 입력 중심의 지원으로 데스크톱·모바일 및 복잡한 상호작용 확장 필요
- 에이전트 판단의 확신도 설명, 중단 빈도와 피드백 방식의 개인화 개선 필요
