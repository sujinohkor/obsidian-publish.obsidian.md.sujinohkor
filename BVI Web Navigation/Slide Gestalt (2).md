*[Slide Gestalt: Automatic Structure Extraction in Slide Decks for Non-Visual Access](https://doi.org/10.1145/3544548.3580921)*
*Yi-Hao Peng*

	Slide Gestalt의 핵심은 슬라이드 사이의 시각적·텍스트적 관계를 자동으로 추출하고, 이를 BVI 사용자가 탐색할 수 있는 계층 구조로 제공하는 것이야. 개별 내용을 읽을 수 있더라도, 그 내용들이 어떻게 묶이고 이어지는지 알기 어렵다는 문제에서 출발해.

# Problem — 무엇을 해결하며, 왜 개발되었는가?
**핵심 문제: 슬라이드의 시각적 구성에 담긴 관계와 전달 방식이 스크린리더에서는 명시적으로 드러나지 않아, BVI 사용자가 전체 구조와 내용의 진행을 직접 추론해야 한다는 점.**

**① 개별 요소에 접근할 수 있어도 덱 전체의 구조를 파악하기 어려움**

기존 슬라이드 접근성 연구는 주로 이미지 대체 텍스트, 다이어그램 설명, 슬라이드 내부 읽기 순서 등 **개별 요소나 개별 슬라이드의 접근성**을 개선해 왔어.

하지만 요소들을 모두 읽을 수 있게 되더라도 다음과 같은 질문은 남아.

- 어느 슬라이드부터 새로운 주제가 시작되는가?
- 같은 제목을 가진 슬라이드들은 하나의 주제로 묶이는가?
- 반복되는 내용은 같은 설명의 재등장인가, 내용을 단계적으로 추가하는 과정인가?
- 현재 주제가 어디에서 끝나는가?

따라서 이 논문은 **요소 수준 접근성에 더해, 덱 수준의 구조적 접근성이 필요하다**고 문제를 정의해.  
_근거: §1, §2.3, §3.4_

**② 시각적 전달을 위해 사용한 디자인 패턴이 비시각 탐색에서는 혼란을 유발함**

저자들은 BVI 독자 4명과의 인터뷰, 정안인 슬라이드 작성자 7명과의 인터뷰, 100개 슬라이드 덱 분석을 통해 세 가지 패턴을 확인했어.

|패턴|작성자가 사용하는 목적|BVI 사용자가 겪는 문제|
|---|---|---|
|**Divider**|구분 슬라이드를 배치해 섹션 전환 표시|짧은 제목만 있는 슬라이드가 왜 반복되는지, 어디까지가 한 섹션인지 파악하기 어려움|
|**Build slides**|비슷한 슬라이드에 요소를 점차 추가해 단계적으로 설명|같은 내용을 반복해서 듣고, 새롭게 추가된 내용을 직접 식별해야 함|
|**Topic split**|하나의 주제를 여러 슬라이드에 나누어 시각적 복잡성 완화|여러 슬라이드가 같은 주제에 속한다는 사실과 주제의 시작·끝을 파악하기 어려움|

예를 들어, 내용이 `A → A+B → A+B+C`로 누적되는 build slides를 순서대로 읽으면 A와 B를 반복해서 듣게 돼. 사용자는 이 반복이 의도된 단계적 설명인지, 별개의 내용인지 판단하고 기억해야 해.

**문제의 원인은 반복 자체보다, 반복의 목적과 범위가 전달되지 않는 데 있어.**  
_근거: §3.1–§3.2, §7.2_

**③ 작성자의 수동 주석에만 의존하기 어려움**

작성자 인터뷰에서는 접근성 문제에 대한 인식 부족과 주석 작성 부담이 확인됐어. 특히 덱의 구조를 별도로 설명하는 작업은 노동집약적으로 인식됐어.

분석한 100개 덱에서는 다음과 같은 결과가 나왔어.

- Build slides를 포함한 덱: **58%**
- Topic split을 포함한 덱: **73%**
- 두 개 이상의 divider를 포함한 덱: **44%**
- 이미지 대체 텍스트와 올바른 읽기 순서를 모두 갖춘 덱: **2%**

이 수치는 해당 표본에 대한 결과야. 모든 슬라이드 자료의 보편적 비율로 해석하면 안 돼.

**개발 이유는 이미 만들어진 덱에서 암묵적인 구조를 자동으로 복원하여, 독자가 반복과 관계를 일일이 추론하는 부담을 줄이기 위해서야.** 주된 사용 맥락은 발표자의 설명 없이 자료를 따로 읽는 상황이야.  
_근거: §2.2, §3.2.3–§3.3_

# Core idea — 제안 방법의 핵심 아이디어는 무엇인가?
**핵심 아이디어: 슬라이드 사이의 시각적 유사성, 텍스트 의미의 유사성, 배치 순서를 함께 분석하면, 작성자가 시각적으로 표현한 그룹과 진행 방식을 추출할 수 있다는 것.**

여기에 **추출한 구조를 스크린리더로 이동 가능한 탐색 단위로 제공한다**는 인터랙션 설계가 결합돼.

**① 개별 슬라이드의 내용뿐 아니라 슬라이드 사이의 관계를 분석**

시스템은 Google Slides API를 이용해 다음 정보를 가져와.

- 텍스트, 이미지, 표, 도형 등 개별 요소
- 요소의 위치와 경계 상자
- 슬라이드 전체 썸네일
- 제목과 요소의 내용

이후 사전학습된 비전·문서 임베딩 모델로 시각 및 내용 정보를 표현하고, 슬라이드 쌍 사이의 코사인 거리를 계산해. 이 거리 행렬에 비지도 정렬 기법을 적용하여 서로 대응하는 슬라이드 그룹을 생성해.

여기서 사용하는 _alignment_는 **유사한 슬라이드 사이의 대응 관계를 찾는 과정**이야. 사용자에게 읽어줄 순서를 새로 정렬한다는 의미는 아니야.  
_근거: §5.1–§5.2, §6.2_

**② 유사성과 덱 내 위치를 함께 이용해 구조의 종류를 구분**

단순히 비슷한 슬라이드를 묶는 것만으로는 충분하지 않아. 같은 디자인이 반복되더라도 그 역할이 다를 수 있기 때문이야.

- 서로 떨어진 위치에서 반복되는 유사한 슬라이드 그룹을 divider 후보로 판단
- Divider를 기준으로 상위 섹션 구성
- 각 섹션 안에서는 제목의 대응 관계를 이용해 연속된 슬라이드 그룹 구성
- 앞서 발견한 시각·내용 대응 그룹과의 관계를 이용해 build 또는 topic split으로 분류

즉, **유사한가뿐 아니라, 어디에서 어떤 방식으로 반복되는가를 이용해 구조적 역할을 판단**하는 접근이야.  
_근거: §5.3_

**③ 구조를 설명과 탐색 기능으로 변환**

추출 결과는 섹션과 하위 섹션의 **두 단계 계층**으로 제공돼. 사용자는 덱 개요에서 섹션·하위 섹션을 거쳐 개별 슬라이드와 요소로 접근할 수 있어.

|제공 정보|탐색에서의 역할|
|---|---|
|덱 전체 개요|전체 분량과 섹션 구성 파악|
|섹션·하위 섹션 제목|관심 있는 내용으로 이동|
|각 그룹의 시작·끝 슬라이드 번호|같은 주제나 패턴의 범위 파악|
|Build·topic split 등의 구조 유형|반복되거나 분할된 이유 파악|
|Build 그룹의 정보가 가장 완전한 슬라이드로 이동하는 안내|누적 내용을 반복해서 읽는 부담 감소|
|개별 슬라이드의 요소 설명|필요한 부분의 세부 내용 확인|

섹션과 하위 섹션에는 HTML heading을 사용해서, 기존 스크린리더의 제목 탐색 기능으로 이동할 수 있게 했어.  
_근거: §4, Figure 3_

**④ 여기서 ‘의도’는 구체적인 구조 패턴으로 다뤄짐**

논문은 작성자의 디자인 의도를 언급하지만, 실제 구현은 주로 **구분하기, 단계적으로 보여주기, 같은 주제를 나누어 제시하기** 같은 패턴을 식별해.

섹션 설명 역시 기본적으로 그룹의 첫 슬라이드 제목을 사용해. 제목이 없으면 큰 이미지의 대체 텍스트나 자동 캡션을 활용해.

따라서 이를 **작성자의 모든 전달 의도를 의미적으로 이해하는 시스템**으로 설명하면 과장이야. 정확히는 **시각적·텍스트적 구성에서 구조 패턴을 추출하고 그 역할을 명시하는 시스템**이야. LLM은 사용하지 않았고, 향후 연구 방향으로 언급돼.  
_근거: §5.4–§5.5_

# Advantages — 기존 접근보다 어떤 점에서 나은가?
**가장 강한 근거는 접근 가능한 내용을 제공하는 것에 계층 구조를 추가했을 때, BVI 사용자의 훑어보기와 정보 탐색 효율이 개선됐다는 점이야.**

다만 기술적 장점과 사용자 이점을 나누어 봐야 해.

**① 시각 정보와 내용 정보를 결합해 구조 추출의 전반적 성능 개선**

50개 덱을 대상으로 한 기술 평가에서는 같은 파이프라인의 입력 정보를 달리해 비교했어.

|입력 정보|전체 Macro-F1|
|---|---|
|시각 정보만 사용|0.76|
|내용 정보만 사용|0.74|
|**시각·내용 정보 결합**|**0.81**|

시각 정보는 divider와 build 패턴을 포착하는 데 유리했고, 내용 정보는 topic split을 식별하는 데 유리했어.

이를 통해 **시각적으로 비슷하다는 이유만으로 다른 내용을 묶거나, 의미가 관련되어 있다는 이유만으로 서로 다른 시각적 역할을 놓치는 문제를 보완**할 수 있어.

단, 결합 방식이 모든 패턴에서 최고 성능을 낸 것은 아니야. 개별 유형에서는 단일 정보 방식이 더 높은 F1을 보이기도 해. 결합 방식의 장점은 **전체 성능**에 있어. 또한 기존의 다른 구조 추출 시스템과 직접 비교한 결과는 아니야.  
_근거: §6.1–§6.3, Table 1_

**② 요소 접근성이 확보된 대조군보다 탐색 효율 개선**

사용자 연구는 BVI 참가자 8명을 대상으로 진행했어. 두 덱은 각각 35개 슬라이드와 8개 섹션으로 구성됐고, 참가자들은 두 인터페이스를 서로 다른 덱에서 사용했어. 순서는 교차 균형화했어.

중요한 점은 **대조군도 이미 접근 가능한 인터페이스**였다는 거야.

- 이미지 대체 텍스트 등 요소 설명 제공
- 각 슬라이드 제목을 heading으로 제공
- 슬라이드 제목 단위 탐색 가능

Slide Gestalt는 여기에 **덱 수준의 계층과 구조 설명**을 추가했어.

|객관적 지표|대조군|Slide Gestalt|
|---|---|---|
|3분 동안 읽은 슬라이드 수|19.4개|**29.3개**|
|질문의 정답을 찾는 시간|96.9초|**45.8초**|
|탐색 중 읽은 중복·반복 요소 수|20.6개|**6.5개**|

두 조건 모두 참가자들이 정답을 찾았어. 차이는 **정답을 찾았는지보다, 얼마나 빨리 적은 반복을 거쳐 찾았는지**에 있어.

따라서 이 실험의 의미는 **요소를 읽을 수 있는 상태에서도, 구조를 탐색 가능하게 제공하면 추가적인 이점이 생긴다**는 것이야.  
_근거: §7.1, §7.3, Table 3_

**③ 전체를 훑고 필요한 부분만 자세히 읽는 전략 지원**

참가자들은 계층 인터페이스에서 먼저 섹션을 훑은 뒤 세부 내용으로 들어가거나, 섹션과 하위 섹션 사이를 오가며 선택적으로 읽었어.

이것은 시스템이 정한 한 가지 순서만 따라 읽게 하기보다, **사용자가 읽기의 범위와 깊이를 조절하도록 지원한다**는 장점이야.

8명 모두 대조군보다 Slide Gestalt를 선호했고, 탐색·훑어보기·읽기 부담에 대한 주관적 평가도 더 긍정적이었어.  
_근거: §7.3_

**④ 이해도에 대한 근거는 구분할 필요**

내용 이해에 대한 자기보고 평가는 7점 척도에서 **3.9점 → 5.8점**으로 높아졌어. 참가자들은 구조를 통해 작성자가 설명을 전개하는 방식도 더 잘 파악할 수 있다고 이야기했어.

하지만 다음을 구분해야 해.

- **직접 측정된 효과:** 탐색 시간 감소, 반복 요소 읽기 감소, 정해진 시간 내 더 많은 슬라이드 탐색
- **주관적으로 보고된 효과:** 내용과 구조를 더 잘 이해했다는 평가
- **충분히 검증하지 않은 효과:** 장기 기억, 깊은 개념 이해, 새로운 과제에 대한 학습 전이

3분 동안 더 많은 슬라이드를 읽었다고 해서, 그 내용을 모두 더 깊게 이해했다고 단정할 수는 없어.

또한 사용자 연구는 **8명·2개 덱**에 한정되고, 실험 중 구조 설명 오류를 경험하지 않았어. 따라서 구조를 잘못 추출했을 때의 사용성까지 검증한 결과는 아니야.  
_근거: §7.1, §7.3, §8_

# Novelty — 무엇이 새로우며, 왜 이전에는 충분히 다뤄지지 않았는가?
**이 논문의 독창성은 구조 추출이나 계층 탐색을 처음 발명한 데 있지 않아. 슬라이드의 반복적 디자인 패턴을 덱 수준 접근성 문제로 정의하고, 자동 추출·설명·비시각 탐색을 연결한 데 있어.**

**① 이미 존재하던 접근과의 차이**

논문 자체도 다음과 같은 선행연구를 인정해.

- 슬라이드의 아웃라인이나 구조를 추출하는 연구
- 슬라이드 간 유사성을 분석하는 연구
- 이미지와 슬라이드 요소의 접근성을 개선하는 연구
- 영상 등 멀티미디어를 계층적으로 탐색하는 연구

따라서 “아무도 슬라이드 구조를 추출하지 않았다”거나 “계층 탐색을 처음 제안했다”고 설명하면 부정확해.

|기존 연구의 중심|Slide Gestalt에서 새롭게 연결한 부분|
|---|---|
|개별 요소와 슬라이드를 읽을 수 있게 만드는 접근성|여러 슬라이드의 관계와 패턴을 이해·탐색할 수 있는 덱 수준 접근성|
|작성·검색 등을 위한 아웃라인과 구조 추출|BVI 독자의 비시각적 자료 소비를 위한 구조 설명과 탐색|
|슬라이드 사이의 유사성 분석|유사성과 등장 위치를 이용한 divider·build·topic split의 역할 구분|
|다른 매체의 계층 탐색|슬라이드 고유의 반복 패턴과 연결한 인터페이스 및 BVI 사용자 평가|

이 비교는 **이 논문이 설명한 선행연구 범위에 근거한 것**이야. 관련 선행연구 원문 전체를 별도로 재검증한 결론은 아니야.  
_근거: §2, §3–§4_

**② 독창성은 세 부분의 연결에 있음**

- **문제 정의:** 시각적으로 유용한 반복 패턴이 비시각 환경에서는 구조 이해와 탐색을 방해할 수 있음을 확인
- **방법 설계:** 시각·텍스트 대응 관계와 슬라이드 위치를 결합하여 구조와 패턴을 자동 추출
- **사용자 검증:** 추출한 구조를 접근 가능한 계층 인터페이스로 제공했을 때, 요소 접근성만 제공하는 조건보다 탐색 효율이 개선됨을 확인

즉, 새로운 단일 AI 모델보다 **문제 발견부터 시스템 구현과 사용자 효과 검증까지 이어지는 연구 전체의 기여**가 중요한 논문이야.

**③ “왜 이전에는 하지 않았는가?”에 대한 근거 있는 해석**

논문이 역사적 이유를 직접 입증한 것은 아니야. 다만 본문을 바탕으로 다음과 같이 해석할 수 있어.

**첫째, 기존 접근성 연구의 주된 초점이 개별 요소에 있었음.**  
누락된 대체 텍스트와 잘못된 읽기 순서가 명확한 문제였고, 여러 슬라이드를 읽는 동안 발생하는 반복·그룹 경계 문제는 별도의 연구 대상으로 다룰 필요가 있었어.

**둘째, 같은 시각적 반복도 서로 다른 역할을 가짐.**  
비슷한 디자인은 divider일 수도, build일 수도, 단순한 공통 템플릿일 수도 있어. 제목과 내용, 시각적 구성, 등장 위치를 함께 해석해야 하므로 단순 유사도만으로 처리하기 어려워.

**셋째, 구조 추출만으로 사용자 이점이 보장되지 않음.**  
어떤 깊이의 계층을 제공할지, 그룹을 무엇으로 설명할지, 반복되는 내용을 어떻게 건너뛰게 할지까지 설계해야 해. 이 논문은 복잡한 계층의 추적 부담을 고려해 UI를 두 단계로 제한했어.

**넷째, 평가에 필요한 데이터가 부족했음.**  
저자들은 다단계 구조와 세밀한 요소 주석을 함께 갖춘 공개 슬라이드 데이터셋을 찾지 못했다고 밝혔어. 그래서 50개 덱의 정답 구조를 직접 주석화했어.

이는 연구의 어려움을 설명하는 근거지만, **이 네 가지가 이전 연구 부재의 원인이라고 확정할 수는 없어.**  
_근거: §2, §5.3, §6_

**④ 독창성과 함께 남는 한계**

- UI가 두 단계 계층을 전제로 하므로 복잡하거나 비계층적인 덱에 대한 대응 제한
- 슬라이드 내부 애니메이션의 진행 과정 미검출
- 슬라이드 요소에 직접 접근해야 하므로 PDF 같은 형식에 그대로 적용하기 어려움
- 첫 슬라이드를 제목 슬라이드로 간주하는 등 휴리스틱에 의존
- 50개 기술 평가 덱이 논문 저자 3명이 만든 자료이므로 작성 스타일의 다양성 제한
- 약 12만 1천 개의 덱을 확보했지만, 전체에 대해 정확도를 평가한 것은 아님. 500개에 파이프라인을 실행하고 그 결과 중 10%를 점검한 탐색적 검토

또한 원문에는 구조 이해도 대조군 점수가 **Table 3에서는 3.8, §7.3 본문에서는 3.0**으로 다르게 기재되어 있어. 발표에서는 이 수치를 핵심 근거로 쓰지 않는 편이 좋아.

# 내 연구에 연결해서 읽을 때 중요한 점
이 논문은 네가 제시한 **“시각적 구성에 담긴 정보를 비시각 탐색의 단서로 바꾼다”**는 연구 방향의 모델로 적합해. 다만 뒷받침하는 범위를 정확히 잡아야 해.

|관점|Slide Gestalt|네가 제시한 연구 방향|
|---|---|---|
|대상|슬라이드 덱|웹페이지|
|추출 대상|슬라이드 사이의 그룹·구조·반복 패턴|시각적 강조와 구조에서 추론한 디자이너의 전달 의도|
|탐색 지원|계층과 그룹 설명을 통한 선택적 이동|읽기 순서를 통한 탐색 안내|
|사용자 목표|훑어보기·검색·정독 등 여러 목적 지원|목표가 불명확하거나 부분적으로 정의된 사용자에 초점|
|입증해야 할 핵심|추출한 구조가 비시각 탐색에 유용한가|추론한 의도에 기반한 읽기 순서가 해당 사용자에게 유용한가|

**Slide Gestalt가 제공하는 근거는 “시각적 구조를 명시적인 비시각 탐색 단서로 제공하면 도움이 될 수 있다”는 것이야.** 여기서 한 단계 더 나아가, **“목표가 불명확한 사용자에게 디자이너 의도 기반 읽기 순서가 도움이 되는가”는 네 연구에서 별도로 검증해야 할 질문**으로 남아 있어.
