*[Enabling Uniform Computer Interaction Experience for Blind Users through Large Language Models](https://doi.org/10.1145/3663548.3675605)*
*Satwik Ram Kodandaram*

# RQ / Research Goal
- 애플리케이션마다 다른 단축키와 탐색 방식으로 발생하는 시각장애 사용자의 조작·인지 부담 완화
- **자연어 명령을 통한 애플리케이션 간 일관된 컴퓨터 상호작용 지원**
- 정확한 UI 요소 명칭을 모르더라도 사용자 의도에 맞는 기능 실행 지원
- 기존 스크린리더 사용 방식 대비 자연어 기반 인터페이스의 효율성·사용성·작업 부담 개선 여부 검증

# Approach
- **GPT-4 기반 보조 시스템 Savant 개발**
- 시각장애인 11명 대상 Wizard-of-Oz 사전 연구를 통한 자연어 명령 수집
- Microsoft UI Automation을 활용한 애플리케이션 제어 트리 구축 및 메뉴·탭 조작으로 드러나는 숨겨진 요소 탐색
- 11개 애플리케이션의 자연어 명령–제어 요소–설정값을 연결하는 예시 생성 및 연구자 검토를 거친 1,200개 예시 구축
- BERT 기반 의미 유사도 검색으로 관련 예시를 추출하고, GPT-4의 few-shot prompting을 통해 사용자 명령을 제어 요소·설정값으로 변환
- 제어 트리에 기록된 경로를 활용한 UI 조작 순서 자동 실행 및 실행 결과 피드백 제공
- 별도의 시각장애인 11명을 대상으로 **JAWS 단독·JAWS+AccessBolt·JAWS+Savant**의 참가자 내 비교 실험 수행
- 6개 애플리케이션에서 과업 성공률·소요시간·키 입력 수·SEQ·NASA-TLX 및 인터뷰 평가

# Findings
- **과업 성공률 향상**: JAWS 6/22건 → AccessBolt 14/22건 → Savant 18/22건
- **평균 과업 소요시간 감소**: JAWS 395초 → AccessBolt 159초 → Savant 101초
- 평균 키 입력 수 감소: JAWS 319회 → AccessBolt 163회 → Savant 44회
- 주관적 과업 용이성 향상: SEQ 평균 2.00점 → 5.60점 → 6.57점으로 증가
- 작업 부담 감소: NASA-TLX 평균 49.90점 → 28.93점 → 16.16점으로 감소
- 사전 수집 명령 145개에 대한 제어 요소·설정값 매핑 정확도 78% 확인
- Savant 조건의 22개 과업 중 첫 시도 성공 11건, 재시도 후 성공 7건, 최종 실패 4건 확인
- 모든 참가자의 Savant 선호 및 단축키 암기·메뉴 탐색 부담 감소에 대한 긍정적 평가

# Limitations
- **단일 제어 요소의 조작 중심 지원**으로 여러 동작을 포함하는 복합 명령 처리 한계
- 여러 애플리케이션을 오가는 작업과 복잡한 순차 작업 자동화 미지원
- 동적으로 등장하는 팝업·하위 창 및 상황에 따라 달라지는 제어 요소 처리 한계
- 자연어의 모호성·LLM 해석 오류·음성 인식 오류로 인한 명령 재입력 및 과업 실패 발생
- 애플리케이션별 제어 트리·예시 데이터 구축과 생성 예시의 수동 검수 필요
- 시각장애인 11명·6개 애플리케이션·Windows 및 JAWS 환경 중심 평가에 따른 일반화 범위 제한
- 영어 중심 검증으로 다국어 지원 효과 미검증
- 음성 사용이 어려운 환경에서의 대체 입력 방식 및 단축키 없이 호출하는 wake-word 기능 개선 필요
